## First_Web_project — 个人主页图片功能打通 + GitHub Pages

**项目背景**：原生 HTML/CSS 个人主页，页面主人是马伊娜（娜娜），上外学生，方向为语言/翻译、AI 辅助学习。

**修复的问题**：`index.html` 引用了两个不存在的文件，导致页面裂图 + 完全无样式。

做的改动：

- `index.html`：图片路径从 `photo.jpg` 改为 `images/photo.jpg`；补 `alt`、`width/height`（防布局抖动）、`decoding="async"`；用 `onerror="this.hidden = true"` 配合 CSS 相邻兄弟选择器 `.avatar:not([hidden]) ~ .photo-hint`，加载失败时降级为虚线占位提示，不再出现裂图；补上原本缺失的 `<meta name="viewport">`；`<div class="box">` 改为语义化的 `<main class="box">`。
- 新建 `style.css`：卡片式居中布局、圆形头像（`object-fit: cover`）、`clamp()` 字号、480px 断点的响应式适配。颜色用 CSS 变量管理。
- 新建 `.nojekyll`（关闭 Pages 的 Jekyll 处理）、`.gitignore`（排除 `.idea/`、`.DS_Store`）。
- 新建 `images/README.md`，说明换照片的规则（全小写 `photo.jpg`，Pages 上文件名区分大小写）。
- 重写 `README.md`：项目说明、Pages 启用步骤、换照片流程、本地预览方式。

**GitHub Pages 情况**：

- Pages **早已启用**，站点地址 `https://muyuna77.github.io/First_Web_project/`。
- 注意踩坑：Pages 的 CDN 对 HTML 有约 10 分钟缓存（`cache-control: max-age=600`），而且**加 query string 不能穿透缓存**，验证新版本只能等缓存过期。静态资源（如新增的 `style.css`）不受影响，会立即 200。
- `GET /repos/{owner}/{repo}/pages` 接口未认证时返回 404，**不能**用它判断 Pages 是否启用；判断依据应该是站点 URL 是否 200，或看返回头里的 `server: GitHub.com`。
